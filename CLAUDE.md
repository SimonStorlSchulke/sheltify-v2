# Code comments

- Do not write comments that only make sense in the context of the current task or conversation: no explanations of a bug that was just fixed, what changed, why something was moved, or which rule used to override it. That belongs in the commit message, not the code.
- Only add a comment when it explains something a future reader can't see from the code itself and that stays true independent of how the code got there. When in doubt, leave it out.
